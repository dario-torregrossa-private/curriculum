**Role: Tech leader**
I am in charge of technological development and dissemination. In particular: assess the problem, identify and develop the correct Machine Learning techniques, make the algorithm reacheable via API and disseminate results trough publications.

EO3D is a project developing a collaborative 3D reference database to improve explosive ordnance (EO) identification. The platform combines 3D models, technical metadata, images, surface scans, volumetric data, and material information through data fusion.

The project includes:

- AI-enhanced feature extraction and enrichment of legacy data
- AI tools for object detection
- Supervised reinforcement learning that integrates human feedback
- Scalable cloud infrastructure for 3D reconstruction and analysis
- Interactive, game-style interfaces for EO identification

The project aims to provide an open-source framework for 3D digitisation and AI-powered identification, supporting safer and more effective decision-making in humanitarian demining. LIST is developing the interfaces and AI tools in collaboration with the Geneva International Centre for Humanitarian Demining (GICHD).



More information is available on the [LIST Research Portal](https://researchportal.list.lu/projects/detail/eo3d).
